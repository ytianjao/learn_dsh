# Progressive Profile Interview

LearnLoop persists nine ordered topics from `goal` through `success-criteria`. The Host exposes one `currentTopic`, accepts one matching native question, stores canonical selected/custom answers, retries an empty answer once, and then falls back to the next direct learner message. Profile drafting remains unavailable until all required topics are answered. Critical profile fields bind to answer IDs; only explanation/example defaults, an absent deadline, and empty notes are Host defaults.
